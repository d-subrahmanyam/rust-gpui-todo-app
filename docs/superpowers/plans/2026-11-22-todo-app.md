# Todo App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Hello World window with a modular GPUI todo app backed by SQLite.

**Architecture:** Plain-Rust core (`model`, `db`, `ui::format`) fully unit-tested; thin GPUI view layer (`ui::*`) that owns a `TodoRepo`, reloads the list after every mutation, and renders header / form / list / footer.

**Tech Stack:** Rust 2024, `gpui-kit 0.10.0` (gpui-component: `Button`, `Label`, `Switch`, `input::{Input, InputState}`, `time::date_picker::{DatePicker, DatePickerState, DatePickerEvent}`), `rusqlite` (bundled), `chrono 0.4`, `dirs`.

**Spec:** `docs/superpowers/specs/2026-11-22-todo-app-design.md`

## Git

- Task 0: initial commit of the existing Hello World project + spec + plan on `master` (add `/target`, `.superpowers/` to `.gitignore`), then work on branch `feature/todo-app`.
- One commit per task, message as given in each task.

## Global Constraints

- DB file: `dirs::data_dir()/gpui-hello/todos.db`; create the directory if missing.
- `rusqlite` with feature `bundled`.
- `target_date` stored as `YYYY-MM-DD`; `created_at` / `completed_at` as RFC 3339.
- List order: newest first (`created_at DESC, id DESC`); completed todos keep their position.
- Title required (non-blank after trim); target date required; description optional.
- Completed rows: faded + title struck through, only the delete action.
- Overdue = open AND `target_date < today`; date text in red.
- `show_completed` setting key, values `"1"`/`"0"`, default `"1"`.
- Footer format: `%A, %-d %B %Y` → "Sunday, 22 November 2026".
- DB errors after startup are shown in the window, never panic.

## Review Focus

1. Whitespace-only title → rejected with "Title is required" (test in Task 1).
2. Title/description with quotes or emoji → round-trip unchanged through SQLite (test in Task 2).
3. Editing a todo must not change its `created_at` (it would jump in the list) (test in Task 2).
4. Hiding completed with all todos complete → empty-state message, open count 0 (test in Task 3).
5. Opening the DB twice (restart) keeps existing rows; schema creation is idempotent (test in Task 2).

**Interfaces:**

```rust
pub struct TodoRepo { conn: rusqlite::Connection }
impl TodoRepo {
  pub fn open(path: &Path) -> rusqlite::Result<Self>;       // creates schema (spec SQL)
  pub fn open_in_memory() -> rusqlite::Result<Self>;
  pub fn default_path() -> PathBuf;                          // data_dir/gpui-hello/todos.db, mkdir -p parent

  pub fn get_setting(&self, key: &str) -> rusqlite::Result<Option<String>>;

}
```

**Files:**
- Create: `src/ui/app.rs` (`TodoApp`), `src/ui/header.rs`, `src/ui/todo_list.rs`, `src/ui/todo_form.rs` (`TodoForm`), `src/ui/footer.rs`

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
```rust
pub struct TodoApp { repo: TodoRepo, todos: Vec<Todo>, show_completed: bool,
  form: Option<Entity<TodoForm>>, editing: Option<i64>, confirm_delete: Option<i64>, error: Option<String> }
impl TodoApp { pub fn new(repo: TodoRepo, window: &mut Window, cx: &mut Context<Self>) -> Self;
  fn reload(&mut self, cx: &mut Context<Self>); }   // errors → self.error
pub struct TodoForm { title: Entity<InputState>, description: Entity<InputState>,
  date: Entity<DatePickerState>, error: Option<String> }
pub enum TodoFormEvent { Submit(NewTodo), Cancel }  // impl EventEmitter
impl TodoForm { pub fn new(existing: Option<&Todo>, window: &mut Window, cx: &mut Context<Self>) -> Self; }
```
`header`, `todo_list`, `footer` are free functions returning `impl IntoElement`, taking data plus `cx.listener(...)` callbacks from `TodoApp`.

Behaviour:
- "+ New todo" → `form = Some(TodoForm::new(None))`, `editing = None`. ✎ → pre-filled form, `editing = Some(id)`.
- Form Save → `validate`; error → shown inline under form; Ok → emit `Submit`. `TodoApp` subscribes: `add` or `update`, close form, `reload`.
- ✓ → `complete`; 🗑 → `confirm_delete = Some(id)` → row shows "Delete? Yes / No" inline; Yes → `delete`.
- Switch "Show completed" → toggles, `set_setting("show_completed", ...)`.
- Completed row: `opacity(0.5)`, title `line_through()`, only 🗑. Overdue: date text red.
- Empty `visible` → `EMPTY_TEXT`. List area scrolls (`overflow_y_scroll`).
- `error` shown as a red banner under the header.
